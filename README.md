# Site Checker

Консольная программа на Python, которая проверяет доступность сайтов по списку из файла и показывает для каждого код ответа или причину сбоя, а также время ответа.

## Возможности

- проверка списка адресов из файла `Sites.txt`;
- для каждого сайта: статус `OK` или `BAD`, код ответа HTTP или причина ошибки, время ответа;
- пустые строки и некорректные адреса не останавливают проверку: программа сообщает о них и идёт дальше;
- ограничение времени ожидания ответа (10 секунд).
- история запросов записывается в отдельный файл results.txt

## Требования

Python 3 (проверялось на Python 3.14, macOS). Только стандартная библиотека, ничего устанавливать не нужно.

## Запуск

1. Впишите адреса в файл `Sites.txt`: один адрес на строку, с `https://`.
2. В терминале перейдите в папку проекта и выполните:

```
python3 site_checker.py
```

Пример `Sites.txt` (часть адресов намеренно неправильная, чтобы показать обработку ошибок):

```
https://www.google.com

https://testurl.com
google.com
https://github.com
htps://github.com
https://ya.ru
https://stepik.org
```

## Пример вывода

```
1. https://www.google.com - OK - 200, время ответа: 0.66 сек.
2. Неверные входные данные
3. https://testurl.com - BAD - по причине: [Errno 8] nodename nor servname provided, or not known
4. google.com - BAD - по причине: unknown url type: 'google.com'
5. https://github.com - OK - 200, время ответа: 0.35 сек.
6. htps://github.com - BAD - по причине: unknown url type: htps
7. https://ya.ru - OK - 200, время ответа: 0.59 сек.
8. https://stepik.org - BAD - 502, время ответа: 8.72 сек.
```

Как читать результат:

- `OK - 200` — сервер ответил кодом 200, указано время ответа;
- `BAD - 502` — сервер ответил кодом ошибки;
- `BAD - по причине: ...` — ответа не было (домен не найден, ошибка соединения, время ожидания вышло) или адрес записан неверно;
- `Неверные входные данные` — пустая строка в файле; номер совпадает с номером строки файла.

## Ограничения

- Проверка идёт только с той машины, где запущена программа. Если сайт недоступен отсюда, это не значит, что он недоступен с других машин.
- Один запуск показывает только один момент. Для более точной диагностики запустите проверку несколько раз с небольшим интервалом.
- Код `200` значит лишь, что сервер ответил. Содержимое страницы программа не проверяет, поэтому нельзя сказать, что страница полная и полезная.
- Время ожидания ограничено значением `maxtime` в коде (сейчас 10 секунд). Более медленные сайты считаются не ответившими.
