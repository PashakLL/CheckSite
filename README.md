# Доступность сайтов

1. Программа site_checker.py делает проверку доступности/недоступности сайтов с машины которой запускается код отвечает кодом или расписывает ошибку.

2. Запускается на языке программирования python 3 из файла site_checker.py предварительно необходимо указать необходимые сайты в файле Sites.txt на каждой строке необходимый сайт.


Пример Sites.txt с правильными и преднамеренно неправильными сайтами: 
```
https://www.google.com

https://testurl.com
google.com
https://github.com
htps://github.com
https://ya.ru
https://stepik.org
```
У проекта только стандартная библиотека Python, ничего ставить не нужно.
В терминале находясь в папке с файлом введите команду 
```
python3 site_checker.py
```

Пример вывода с правильными и преднамеренно неправильными сайтами:
```
1. https://www.google.com - OK - 200, время ответа: 0.66 сек.
2. Неверные входные данные
3. https://testurl.com - BAD - по причине: [Errno 8] nodename nor servname provided, or not known
4. google.com - BAD - по причине: unknown url type: 'google.com'
5. https://github.com - OK - 200, время ответа: 0.35 сек.
6. htps://github.com - BAD - по причине: unknown url type: htps
7. https://ya.ru - OK - 200, время ответа: 0.59 сек.
8. https://stepik.org - BAD - 502, время ответа: 8.72 сек.
```


# Ограничения
1. Проверка доступности сайтов происходит только с локальной машины. если сайт не доступен с машины с которой идет запуск программы не означает, что этот же сайт не доступен с другой машины.
2. Для более точной диагностики необходимо получить программой несколько результатов с коротким промежутком по времени для того, чтобы быть уверенным в его достоверности.
3. Если сайт ответил OK - 200, это означает, что операция завершилась успешно и сайт (сервер) ответил кодом 200, но это не означает, что страница по смыслу полная, корректная и полезная для пользователя.
4. Программа ждет результат от сайта в переменной maxtime, ожидание ограничено этим значением в коде (сейчас 10 секунд), более медленные сайты будут считаться не ответившими.
